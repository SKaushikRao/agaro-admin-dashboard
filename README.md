# Agora Admin Dashboard (Sanity Studio)

This is the standalone administrative and content-management Studio for the Agora Learning Platform, powered by Sanity CMS v3.

## Features & Content Models
- **Homepage & Site Settings**: Configure hero text/images, featured subject cards, featured articles, and upcoming events.
- **Subjects & Disciplines**: Create, order, categorize, and configure subject paths, topics, quotes, and statistics.
- **Learning Paths**: Define structured step-by-step journeys and connect articles/units.
- **Articles & Essays**: Rich Portable Text with inline media, authors, categories, tags, read times, and SEO metadata.
- **Resources & Materials**: Educational assets (videos, books, papers, courses, podcasts, websites, PDFs).
- **Authors & Faculty**: Manage authors, scholars, and academic institutions.
- **Events & Webinars**: Manage virtual lectures, seminars, and calendar items.
- **Taxonomy**: Manage categories and tags.

## Development

```bash
# Install dependencies
npm install

# Start Sanity Studio locally on port 3333
npm run dev

# Run Typecheck
npm run typecheck

# Build Studio for production deployment
npm run build
```
